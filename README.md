## Overview

Bass Scales Trainer provides a dedicated practice environment for bass players studying major, natural minor, and modal scales in every key. Each exercise can be adjusted with different playing approaches and rhythmic patterns, allowing practice sessions to be organized around repeatable goals.

Alongside practice feedback, the app uses SM-2 spaced repetition to help schedule future work. Players can enter comfort ratings, review practice history and progress grids, and attach notes to individual practice slots. A built-in metronome supplies slot-specific tempo support, while browser storage keeps practice information available locally. JSON export and import make it possible to preserve or move a practice setup.

## What It Includes

- Study major, natural minor, and modal scale types

## Practice Workflow

Use the following sequence for a typical session:

1. Select a scale category, including major, natural minor, or a mode.
2. Choose one of the 12 keys.
3. Set a playing variation and a rhythmic variation.
4. Configure the practice slot's BPM with the metronome.
5. Play the selected exercise on bass guitar.
6. Submit a comfort rating after practicing.
7. Write a note when a key, movement, or rhythm deserves additional work.
8. Consult the progress grid and history view to see completed practice.
9. Return to the next repetition recommended by the spaced repetition schedule.

The JSON export and import controls can be used to back up or transfer practice data.

## Settings and Stored Data

There is no separate configuration file. Bass Scales Trainer is controlled from within the application, where the following practice details can be managed:

- Current scale and key

These records are kept in the browser's local storage. Export the data as JSON for a portable backup, then use JSON import to load an earlier backup.

## Frequently Asked Questions

### Who should use Bass Scales Trainer?

The app is designed for bass guitar players seeking a structured approach to scales, keys, rhythmic patterns, and multiple playing variations.

### Do I need to install anything?

No. It is an HTML application that opens directly in a web browser.

### Where does the app keep my practice records?

The browser saves practice data in local storage associated with the current site or local file context.

### How do I preserve or move my progress?

Select JSON export to save the records to a file. That file can later be restored through the JSON import control.

### Can each exercise have its own tempo?

Yes. The metronome allows a BPM setting for every practice slot.

### Why can I no longer see my progress?

Confirm that you are using the same browser and storage context used previously. If you made a JSON backup, import it to recover the saved practice data.

### What purpose do comfort ratings serve?

Comfort ratings give the spaced repetition system feedback for arranging future reviews. They can also be undone or reset if necessary.

### Where can I find newer versions?

Open the hosted [latest build](https://dylan-graykaga6779.github.io/bass-scales-trainer-app/) or review the repository for newer HTML releases and updates.
